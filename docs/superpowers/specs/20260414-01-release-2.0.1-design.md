# release/2.0.1 リリース準備 設計書

## 目的

Issue #428 の修正（自己閉じタグ `<div class="page" />` の改ページ対応）を 2.0.1 patch release としてリリースするための準備作業を行う。

## スコープ

### 対象

- `release/2.0.1` ブランチの作成（`develop` から分岐）
- `package.json` のバージョンを `2.0.0` → `2.0.1` に更新
- `CHANGELOG.md` に 2.0.1 エントリを追加
- `README.md` / `README.ja.md` の更新:
  - Page Break (改ページ) セクション: 両形式（`<div class="page"/>` と `<div class="page"></div>`）を併記
  - Release Notes セクション: 2.0.1 エントリを 2.0.0 の上に追加
- `styles/markdown-pdf.css` の Page Break コメント更新

### 対象外

- `develop` / `master` へのマージおよび PR 作成
- 実装コードの変更
- テストの追加・変更
