# release/2.1.0 リリース準備 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `develop` に積み上がった変更を 2.1.0 として確定リリースする (`package.json` の version bump + `CHANGELOG.md` の見出し確定 + `README.md` / `README.ja.md` の見出し確定)。

**Architecture:** `feature/release-2.1.0-spec` を `develop` に `--no-ff` で merge 後、`release/2.1.0` を `develop` から worktree (`.worktrees/release-2.1.0/`) として作成し、その上で関心ごとに分離した 3 コミット (chore: version / docs: CHANGELOG / docs: READMEs) を積む。`develop` / `master` への戻しマージ・タグ付け・公開は本計画のスコープ外。

**Tech Stack:** Git (worktree)、`package.json` (Node.js)、Markdown (CHANGELOG / README)。

**設計書:** `docs/superpowers/specs/20260524-02-release-2.1.0-design.md`

---

## ファイル構成

本計画で変更するファイルは 4 つのみ。すべて既存ファイルの修正。

- **Modify:** `package.json` — `"version"` を `"2.0.1"` → `"2.1.0"`
- **Modify:** `CHANGELOG.md` — 先頭の `## X.Y.Z (YYYY/MM/DD)` を `## 2.1.0 (2026/05/24)` に
- **Modify:** `README.md` — 2 箇所の `### X.Y.Z` を `### 2.1.0` に
- **Modify:** `README.ja.md` — 2 箇所の `### X.Y.Z` を `### 2.1.0` に
